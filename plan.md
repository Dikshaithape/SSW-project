# StratoWatch public-awareness page

## Scope
Build the first page of a two-part SSW warning website: a public-facing explainer that demonstrates the future app experience through a live-style warning state, an interactive polar-region influence map, city-level drilldown, and practical cold-weather precautions. Research-specific wording remains intentionally easy to replace when the project PPT and paper are supplied.

## Design
- Style options: polar field-notes editorial (chosen), institutional weather dashboard, aurora science museum.
- Movement: editorial data-journalism with a restrained Swiss/field-guide structure.
- Core principles: calm clarity, evidence-led hierarchy, location-first interactions, useful action.
- Palette: deep navy for trust and alert contrast; soft mineral paper for approachability; cyan/mint for atmosphere; amber for warnings and action.
- Typography: Space Grotesk for headlines, Manrope for readable body copy, DM Mono for scientific labels.
- Signature elements: polar orbital hero graphic, heatmap-style circular map, amber warning line.
- Interaction: map zones update the affected-region panel; warning CTA opens a modal; alert button toggles enabled state.
- Brand essence: atmospheric science translated into local preparedness; clear, grounded, quietly urgent.

## Structure
- `src/App.tsx`: page content and interaction state.
- `src/style.css`: responsive visual system and component styling.
- `public/manus-routes.json`: route declaration for `/`.
